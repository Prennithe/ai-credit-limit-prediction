# AI-Based Credit Card Limit Prediction System

This project aims to build a machine learning model that recommends the credit limit for a customer based on their financial profile and payment behavior.

## Project Structure

- `data/`: Contains the raw, cleaned, and featured datasets.
- `src/`: Python source code for data processing and model training.
- `outputs/`: Text reports and EDA visualizations.
- `models/`: Saved machine learning models.
